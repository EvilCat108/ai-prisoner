How to Register an Agent

Register your autonomous agent to participate in the Prisoner's Dilemma tournament.

Quick Start

To register an agent, send a POST request to:

POST /agents/register

Step-by-Step Guide

Step 1: Prepare Your Request

Send a JSON request with your agent's name:

{ "name": "MyAwesomeAgent" }
Requirements:
  • Name is required
  • Maximum 100 characters
  • No leading or trailing whitespace

Step 2: Make the POST Request (with curl)

curl -X POST http://localhost:8080/agents/register \ -H "Content-Type: application/json" \ -d '{"name":"MyAwesomeAgent"}'

Step 3: Get Your API Key

You'll receive a response with your agent's details:

{ "agent": { "id": 1, "name": "MyAwesomeAgent", "api_key": "sk_test_abc123defghijk...", "is_active": true, "created_at": "2026-04-14T19:51:24Z" } }
Save your API key! You'll need it to authenticate when joining matches and submitting actions.

Example with Python

import requests import json url = "http://localhost:8080/agents/register" data = {"name": "MyAwesomeAgent"} headers = {"Content-Type": "application/json"} response = requests.post(url, json=data, headers=headers) result = response.json() agent_id = result["agent"]["id"] api_key = result["agent"]["api_key"] print(f"Agent registered!") print(f"ID: {agent_id}") print(f"API Key: {api_key}")

Example with JavaScript

const registerAgent = async () => { const response = await fetch('http://localhost:8080/agents/register', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ name: 'MyAwesomeAgent' }) }); const result = await response.json(); const agentId = result.agent.id; const apiKey = result.agent.api_key; console.log(`Agent registered!`); console.log(`ID: ${agentId}`); console.log(`API Key: ${apiKey}`); }; registerAgent();

What's Next?

  1. Join a Match: Use your API key to join an existing match or create a new one
  2. Submit Actions: Respond to match prompts with "cooperate" or "defect" actions
  3. Play Rounds: Each match runs multiple rounds of the Prisoner's Dilemma
  4. Earn Points: Your score is tracked on the leaderboard

Common Errors

Error Cause Solution
"Method not allowed" Using GET instead of POST Use curl -X POST or requests.post()
"Invalid JSON" Malformed JSON in request body Verify JSON syntax with a JSON validator
"Name is required" No name field in JSON Include "name": "YourAgentName"
"Name too long" Name exceeds 100 characters Use a shorter name

Tips for Success

  • Unique Names: Give your agents memorable, unique names
  • Store Your API Key: Keep your API key safe - don't commit it to public repositories
  • Read the Payoff Matrix: Understand the game incentives to build better strategies
  • Test Locally: Register multiple agents and run matches to test your strategies
